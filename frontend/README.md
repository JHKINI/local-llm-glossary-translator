# 반도체 용어 번역기 (프론트엔드)

로컬 Ollama(qwen3.5:4b) + FastAPI 번역 서버에 연결되는 React 화면입니다.
반도체 용어집을 적용해 번역하고, 실제로 적용된 용어를 형광펜으로 표시해 줍니다.

## 실행 방법

필요한 것: Node.js 18 이상 (`node -v`로 확인)

1. 백엔드를 먼저 켭니다. (Ollama가 켜져 있어야 해요)

   ```
   uvicorn main:app --port 8002
   ```

2. 이 폴더에서 프론트엔드를 켭니다.

   ```
   npm install
   npm run dev
   ```

3. 브라우저에서 http://localhost:5173 을 엽니다.

백엔드 주소가 다르면 이 폴더에 `.env` 파일을 만들고 한 줄을 적습니다.

```
VITE_API_URL=http://127.0.0.1:8000
```

## 파일 구조

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 뼈대. 반응형의 출발점인 viewport 설정이 여기 있어요 |
| `src/App.jsx` | 화면과 동작 (상태, 번역 요청, 용어 표시) |
| `src/App.css` | 모든 스타일. 모바일 기준으로 쓰고 넓은 화면에서 덮어써요 |
| `src/api.js` | 서버 호출 (`/` 상태 확인, `/translate` 번역) |
| `src/glossary.js` | 내장 반도체 용어집 10개 (영어 → 한국어) |

## 반응형이 동작하는 방식

- **viewport 설정**: 폰이 화면을 데스크톱 폭으로 줄여 보여주지 않게 합니다.
- **모바일 먼저**: 기본 CSS는 좁은 화면 기준이고, `@media (min-width: …)`로 넓은 화면만 덮어씁니다.
- **560px 이상**: 용어 추가 입력줄이 위아래 → 한 줄로 바뀝니다.
- **860px 이상**: 원문과 번역 결과가 위아래 → 좌우로 나란히 놓입니다.
- **자동으로 칸 수가 정해지는 목록**: 적용된 용어, 용어집, 상세 정보는 `auto-fill` / `auto-fit` 그리드라서 화면 폭에 맞춰 칸 수가 저절로 바뀝니다.
- **글자·여백**: `clamp()`로 최소~최대 사이에서 부드럽게 변합니다.
- **터치**: 버튼과 입력칸은 높이 44px 이상, 입력 글자는 16px 이상입니다.
- **움직임 줄이기**: OS에서 "동작 줄이기"를 켜면 형광펜 애니메이션이 꺼집니다.

확인하는 방법: 브라우저에서 F12 → 기기 툴바(Ctrl+Shift+M)를 켜고 폭을 줄였다 늘려 보세요.

## 한국어 → 영어 번역

용어집은 영어 → 한국어 쌍으로 관리하고, 한국어를 원문으로 고르면 화면이 key와 value를 뒤집어서 서버에 보냅니다.
이때 백엔드가 한국어 key를 찾을 수 있어야 해서, `main.py`의 용어집 필터에 한국어용 분기가 필요해요. (`\b`는 "수율을"처럼 조사가 붙은 한글을 못 찾습니다.)
